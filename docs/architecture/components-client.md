# Client-Komponenten

## App Shell

Verantwortlich für:

- globale Navigation
- Routing
- Theme
- PWA-Updates
- globale Fehlerbehandlung

## Overview Feature

Verantwortlich für:

- Datumsauswahl
- Fixture-Liste
- Top-Wettbewerbe
- Tabellen-Vorschau
- Live-Aktualisierung der angezeigten Fixtures

## Match Feature

Verantwortlich für:

- Spielkopf
- Ereignisse
- Statistiken
- Aufstellungen
- Tabellenkontext
- Formanzeigen

## Competition Feature

Verantwortlich für:

- Wettbewerbskopf
- Saison- und Rundenauswahl
- Fixture-Liste
- Tabellen
- Gruppendarstellung

## Shared UI

Enthält wiederverwendbare, fachlich möglichst neutrale UI-Bausteine.

## Shared Data Access

Enthält technische Zugriffe auf die Reelscore API und Live-Verbindungen.
