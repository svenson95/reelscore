# App Shell

Der App Shell enthält globale Bestandteile der Benutzeroberfläche, die unabhängig von der aktuell geöffneten Page verfügbar sind.

Dazu gehören insbesondere Header und Footer.

## Header

### App Logo

Das App-Logo dient als Navigation zur Overview Page.

Ein Klick auf das Logo führt unabhängig von der aktuell geöffneten Seite zurück zur Overview Page.

### Competition Selector

Über den Competition Selector können die verfügbaren Wettbewerbe ausgewählt werden.

Die Auswahl eines Wettbewerbs führt zur Competition Page des jeweiligen Wettbewerbs.

## Footer

### Muted App Logo

Der Footer zeigt das App-Logo in einer dezent ausgegrauten Darstellung als rein visuelles Element ohne Navigation oder weitere Interaktion.

### Link List

Der Footer enthält allgemeine und rechtlich relevante Links, beispielsweise:

- Impressum
- Datenschutz

Die Link-Liste kann zukünftig um weitere Einträge erweitert werden.
